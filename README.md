# URL Shortener

Приложение для сокращения URL-адресов на языке Clojure.

Проект состоит из сервера и консольного клиента. Клиент отправляет запросы серверу, а сервер обрабатывает их и сохраняет ссылки в базе данных SQLite.

## Используемые технологии

- Clojure 1.12.2
- Java 21
- Leiningen
- Ring и Jetty
- SQLite

## Возможности программы

В программе есть пять действий:

1. Создать — создать короткую ссылку.
2. Показать — получить исходный URL по короткой ссылке.
3. Изменить — изменить адрес существующей ссылки.
4. Удалить — удалить ссылку.
5. Выйти — завершить программу.

Если ссылка не найдена, программа выводит `Ответ: Ошибка`.

## Сборка проекта

Для сборки необходимы Java 21 и Leiningen.

Откройте PowerShell в папке проекта и выполните:

```powershell
lein deps
lein uberjar
```

После сборки JAR-файл находится по пути:

```text
target/uberjar/url-shortener-0.1.0-SNAPSHOT-standalone.jar
```

## Запуск программы

Для правильного отображения русского текста в PowerShell выполните:

```powershell
chcp 65001
$env:JAVA_TOOL_OPTIONS = "-Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8"
```

### Запуск сервера

В первом терминале выполните:

```powershell
java -jar .\target\uberjar\url-shortener-0.1.0-SNAPSHOT-standalone.jar 8080
```

Сервер запустится на порту 8080. База данных SQLite создаётся автоматически при первом запуске.

### Запуск клиента

Откройте второй терминал PowerShell в папке проекта и выполните те же команды настройки кодировки, затем:

```powershell
java -jar .\target\uberjar\url-shortener-0.1.0-SNAPSHOT-standalone.jar
```

Появится меню:

```text
=== URL Shortener ===
1. Создать
2. Показать
3. Изменить
4. Удалить
5. Выйти
Выберите действие:
```

## Пример работы

Создание ссылки:

```text
Выберите действие: 1
Введите обычный URL:
> https://example.com/test
Ответ: 4af5d0a7
```

Получение ссылки:

```text
Выберите действие: 2
Введите короткий URL:
> 4af5d0a7
Ответ: https://example.com/test
```

Короткий идентификатор создаётся автоматически, поэтому в каждом случае он будет другим.

Для изменения ссылки нужно выбрать пункт 3 и ввести короткий идентификатор и новый URL через пробел.

Для удаления ссылки используется пункт 4.

## REST API

Сервер поддерживает четыре HTTP-метода:

| Метод | Адрес | Действие |
|---|---|---|
| POST | `/normal-url` | Создание ссылки |
| GET | `/short-url?url=ID` | Получение ссылки |
| PUT | `/short-url` | Изменение ссылки |
| DELETE | `/short-url` | Удаление ссылки |

## Структура проекта

Основные файлы находятся в папке `src/url_shortener`:

- `core.clj` — запуск приложения.
- `cli.clj` — консольное меню.
- `client.clj` — отправка HTTP-запросов.
- `server.clj` — обработка запросов.
- `db.clj` — работа с базой данных.
